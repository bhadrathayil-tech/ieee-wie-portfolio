# Personal Portfolio Website

A clean, responsive, and modern personal portfolio website built as part of the IEEE WIE Task Submission. Designed to highlight academic background, technical skills, and featured projects.

## 🚀 Features
- **Responsive Layout:** Optimized for mobile phones, tablets, and desktop viewports using Tailwind CSS.
- **Interactive Navigation:** Mobile hamburger menu with smooth section scrolling.
- **Interactive Contact Form:** Client-side JavaScript validation and success feedback state.
- **Modern UI/UX:** Dark-mode aesthetic with custom accents and card hover states.

## 🛠️ Technology Stack
- **HTML5** – Semantic document structure
- **Tailwind CSS** – Styling and responsive layout utilities
- **JavaScript (ES6+)** – Interactive mobile menu and form handling
- **FontAwesome** – Scalable vector icons
